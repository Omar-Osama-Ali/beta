# MYRIAM & AHMED — Wedding Invitation

Static mobile-first wedding invitation for GitHub Pages.

## Edit before publishing
Open `script.js` and change:
- `eventDate`
- `eventDateArabic`
- `googleAppsScriptUrl` when Google Sheets storage is ready

The Google Maps link and uploaded `assets/song.mp3` are already included.

## Photos
Create `assets/photos/` and replace the gallery placeholders in `index.html` with `<img>` elements.

## GitHub Pages
Upload the whole folder to your repository. Then enable GitHub Pages from Settings → Pages → Deploy from branch → main/root.
