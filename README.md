# Omar Osama — Official Digital Hub

A responsive, static personal link hub built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure, link destinations, SEO metadata
- `style.css` — responsive visual system, CSS 3D sculpture, cards, motion, and layout
- `script.js` — restrained pointer interactions, current year, optional Google Analytics

## Deploy
Upload the files to the `Link-Hub` repository/folder served by GitHub Pages. No build step or backend is required.

## Optional Google Analytics
Set `GA_MEASUREMENT_ID` in `script.js` to your GA4 measurement ID. It is blank by default.

## Notes
All existing configured destinations are retained. Verify contact destinations before publishing if your contact details change.
