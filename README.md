# Omar Osama Premium Portfolio

Static portfolio rebuild based on the supplied Omar Osama site content and assets.

## Deploy
Upload the contents of this folder to the GitHub Pages repository root. The site is static HTML/CSS/JS and does not require a build step.

## Important
GitHub Pages cannot provide server-side rate limiting, CSRF protection, database security, authentication or secure file-upload processing because this build has no backend. If those capabilities are added later, implement the controls at the backend/hosting layer.

Before production: verify all project imagery/licenses, confirm legal copy for the intended jurisdiction, enable HTTPS in GitHub Pages, submit `sitemap.xml` to Search Console, and review repository history for secrets.
